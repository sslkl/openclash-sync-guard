配置控制中心

OpenClash同步器

统一管理主配置与两个机场文件。所有写入都会先执行 YAML（配置文件格式）语法检查、结构检查和 SHA-256（摘要）并发保护。

术语说明

Stage（暂存）
生成并校验候选文件，但不切换当前运行配置。

ACTIVE（当前启用配置）
OpenClash 当前选择的静态主配置路径。

SHA-256（摘要）
文件的内容校验值，用于识别变化和防止覆盖。

UCI（OpenWrt 配置接口）
路由器的系统配置数据库；本管理台不会更改 ACTIVE/UCI。

日常操作

快速更新

选择目标路由器后，按单项按钮执行。主配置会先生成 Candidate（候选配置）、通过检查和备份后再原子替换；不会自动 reload（重新加载）运行内核。

主

更新主配置文件

重新生成 Candidate（候选配置），通过 Mihomo（OpenClash 核心）检查、备份后更新静态主配置。

M

更新 Maying 机场文件

调用 OpenClash 单订阅更新入口；可能触发配置检查。

N

更新 Nexitally 机场文件

只更新目标路由器本机的 ProviderBase.yaml。

独立定制

域名/IP 分流与 Fake-IP Filter

自定义分流规则会放在主配置规则最前面，优先于订阅规则；Fake-IP Filter（虚拟 IP 过滤黑名单）中的域名将使用真实 DNS（域名解析）结果，不分配 Fake-IP。

域名/IP 分流规则

DOMAIN 为精确域名，DOMAIN-SUFFIX 为域名后缀，IP-CIDR/IP-CIDR6 为 IPv4/IPv6 网段；DIRECT 表示直连，也可选择当前主配置中的业务分组。业务分组名来自主配置，保持原名显示。

输入示例DOMAIN · api.example.com · DIRECTDOMAIN-SUFFIX · example.com · AIIP-CIDR · 198.51.100.0/24 · 🎯Direct

Fake-IP Filter 黑名单

适合局域网设备、局域网域名或不兼容 Fake-IP 的服务。禁止单独输入 *。

输入示例printer.lan*.example.com+.example.com

高风险操作

回滚主配置文件

恢复最近一个内容不同且通过校验的主配置备份。回滚前将再次备份当前文件并执行 Mihomo（OpenClash 核心）静态检查。

注意

回滚只替换静态主配置并重放当前定制项；不会切换 ACTIVE（当前启用配置）、写入 UCI（OpenWrt 配置接口）或 reload（重新加载）运行内核。历史备份不会删除。

输入必须完全一致，用于避免误触。
